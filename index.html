05 / A FEW DETAILS

Before you ask.

Compatibility, installation and everyday use.

Does Astreis work on every Linux distro?

This release targets 64-bit Zorin OS 18, Ubuntu 24.04 and compatible systems with glibc 2.39 or newer. It ships as a .deb. Other distributions, architectures, Windows and macOS aren't supported by this package.

Do I need an account?

An Astreis account is required for AI chat and real-time voice. You can monitor hardware, review supported changes and clean temporary files without signing in.

Does it change things automatically?

Monitoring and discovery read your system. Applying a profile, cleanup, setup action or supported fix requires your confirmation. Available actions depend on your hardware and system. Some fixes support undo; removed cache files don't.

What does Deep Clean remove?

Supported temporary files and caches that applications can recreate. You review the categories and plan first. Astreis rechecks files before removal and skips active, changed, protected or uncertain data.

Are AI chat and voice ready out of the box?

After you sign in, Chat connects through the shared Astreis service. You don’t need your own API key. Online features need an internet connection and available services. If Chat is under heavy load, try again shortly. Core monitoring, cleanup and system tools work independently.

Can I turn the visual effects down?

Yes. The app includes Low Detail mode and sound settings. Low Detail mode is enabled automatically on first launch below 8 GiB RAM or four physical CPU cores, and your manual choice takes priority. This website also respects reduced-motion preferences and has a pause-animation control.

How do I update or uninstall?

Install a newer compatible .deb through your software manager to update. To remove the app, use your package manager or sudo apt remove astreis. Personal settings stay in your user profile; uninstalling doesn't undo system changes you applied.
