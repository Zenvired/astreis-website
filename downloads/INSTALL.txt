ASTREIS 0.1.6

64-bit Zorin OS 18 / Ubuntu 24.04 and compatible systems with libc6 >= 2.39.

Open Astreis_0.1.6_amd64.deb with your software manager and choose Install.
Alternatively, open a terminal in this folder and run:

  sudo apt install ./Astreis_0.1.6_amd64.deb

The package manager installs required dependencies. Internet access may be
needed for missing packages. Astreis appears in your application menu.

Flatpak for x86-64 Linux:
  flatpak install --user ./Astreis_0.1.6_x86_64.flatpak

The bundle uses the GNOME 50 runtime from Flathub. Flatpak limits access
to the host hardware, user files, package manager, and system settings.

Verify the website downloads:
  sha256sum --ignore-missing -c SHA256SUMS

Uninstall the Debian package:
  sudo apt remove astreis

Uninstall the Flatpak bundle installed for your user:
  flatpak uninstall --user com.zenvire.astreis

To remove the Flatpak and its saved settings and data:
  flatpak uninstall --user --delete-data com.zenvire.astreis

System changes you applied through Astreis persist after uninstalling.
AI chat and realtime voice require their external service configuration.
No developer API credentials or paid-license enforcement are included.
